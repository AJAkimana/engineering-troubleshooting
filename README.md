# 🛠️ Engineering Notes & Fixes

This repository is a personal knowledge base and troubleshooting guide that documents common (and uncommon) issues encountered in software engineering. It spans across:

- 🖥️ Programming Languages (Python, JavaScript, TypeScript, etc.)
- 🐳 DevOps & Infrastructure (Docker, CI/CD, Linux, system configuration)
- 🛜 Networking & APIs
- 🧪 Testing & QA
- 🔒 Security Tips
- ☁️ Cloud & Hosting (AWS, VPS, etc.)

## ✨ Purpose

- Serve as a reference for recurring technical problems and solutions.
- Help others quickly resolve bugs, errors, and configuration quirks.
- Improve onboarding and handover for teammates or collaborators.
